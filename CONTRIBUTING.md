# Found another ridiculous combination?

We'd love to see it. You don't need to write code or know your way around GitHub.

[← Main page](README.md)

## Suggest a game

[Open an issue](https://github.com/connorplaz14-blip/interdimensional-gaming/issues/new) and include:

- **The games:** for example, “Minecraft × Skyrim”.
- **The original creator:** a project, profile or original upload link.
- **What actually crosses over:** movement, blocks, combat, maps, or two games running together.
- **Where to see it:** a demo or gameplay link.
- **Can people try it?** Share the original download or setup guide if there is one. It's fine if there isn't.

Don't worry about formatting. A few sentences and the original links are enough.

## Help keep the list honest

A new costume or texture pack isn't the same as another game's gameplay running inside it. We're interested in meaningful crossovers, and we label works in progress and demo-only projects accordingly.

We prefer original creator links over reuploads. We don't invent release links, installation instructions or permission based on a viral clip.

## Share footage

Link to your original recording and say whether you're its creator. We'll record permission and credit before considering it for the TV feed. Sending a link doesn't automatically put it on the website.

## Correct a credit or request removal

Use the same issue link. Tell us what the page currently says, what should change, and the original source. Creators don't need to submit code to have a correction considered.

## For people contributing code or archives

Keep changes focused. Preserve original licence files, notices and creator credits. Don't upload game installations, ROMs, personal account details or private website files.

Saved source copies need an exact upstream version and file checksum in the archive records. Playable downloads should point to the original creator; don't confuse source archives with installers.
