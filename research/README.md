## How we choose entries

We look for an identifiable creator, an original project or demo, and a clear description of what crosses between games. A repository or release page isn't proof we've run it: our new checks are documentation checks, not play-tests.

Where setup is uncertain or a project is unfinished, we say so in the [game guide](../games/README.md).
