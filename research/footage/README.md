## If you're helping with future footage

1. Use your own recording or footage with documented creator approval.
2. Keep the untouched original and record its source and permission.
3. Edit a clean copy, then record the changes and creator credit.
4. Update the website's playlist separately; changing this research folder won't update the TV.

A code licence doesn't automatically give permission to reuse an unrelated YouTube, X, TikTok or Instagram video.
