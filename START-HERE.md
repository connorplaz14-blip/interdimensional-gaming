# Want to try a mashup?

You don't have to be a programmer. Some creators provide downloads and setup guides; others are sharing experiments that need more work to run.

[← Main page](README.md) · [Browse the game guide](games/README.md)

## The short version

1. **Pick a game in our [game guide](games/README.md).** Check the games and computer it needs before downloading anything.
2. **Open the creator's download link.** On a GitHub Releases page, look under **Assets** for the file named in their instructions. Avoid “Source code” unless you want to work on the code.
3. **Read the creator's setup guide.** A mod for one game version might not work on another. Some need a separate mod loader or a second game running in the background.
4. **Back up your saves and try it.** These can be experimental. Follow offline-only instructions, especially for Elden Ring mods.

The creator's guide is the final word on installation. Our pages help you choose; they don't replace those instructions.

## What do the labels mean?

| Label | In ordinary English |
| --- | --- |
| **Download available** | The creator has published mod files. You still need to follow their setup steps. |
| **Setup required** | Getting the project running may involve extra tools, building code or a particular machine. |
| **In development** | You can follow the work, but shouldn't expect a finished game. |
| **Demonstration** | There's footage of the idea. That alone doesn't mean there's a public download. |
| **Source archived** | We've saved a version of the project files. This isn't a game installer. |

## A few words you'll see

**Mod:** an add-on that changes a game.

**Mod loader:** a tool that lets a game load those add-ons. Fabric, BepInEx, SKSE, F4SE and me3 are examples; different games use different tools.

**Passthrough:** two games run together and share information. One might handle Minecraft's blocks and movement while the other supplies Skyrim's scenery and enemies.

**Source code:** the instructions a developer writes to make a program work. Turning those files into a runnable program is called **building** or **compiling**.

**Release:** a packaged version published by the creator. Usually where players should look first.

**Snapshot:** a saved copy of the code at one point in time. Our archives don't update themselves when a creator releases something new.

## Can I use a Mac, console or an older laptop?

Check each project. Most new additions document Windows setups. The original Minecraft × Elden Ring / Monster Hunter bridge documents an Apple Silicon + CrossOver setup, which is different from a normal Mac game install.

Don't assume a mashup works just because both games work separately. Running two games at once can need more memory and graphics power.

## Are the original games included?

No. You need your own game copies and, where requested, your own extracted game files. We link to mods and keep selected source archives; we don't provide commercial games or ROMs.

## Something isn't working?

Check the creator's troubleshooting guide and known issues first. Report bugs in their mod to their project, with your game version and what happened. For a wrong link or description here, [tell us](https://github.com/connorplaz14-blip/interdimensional-gaming/issues/new).
